# data-acquisition

Transport and archive layer for primary-source public-domain inventory data
(US EIA and USDA) used by a systematic-trading research programme.

**This repository is not a data source.** Every artifact originates from an
official government publication; the official URL, publication date and
SHA-256 of the raw bytes are recorded alongside it. See `BRIDGE_REPORT.md`.

All data here is US Government work in the public domain.
